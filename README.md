# 📝 Braille & Korean Simultaneous Learning Device **"Dodam"**  
### 🏆 **Excellence Prize | 2024 Creative Engineering Design Competition**  

📌 **Team Name:** Dodam  
📌 **Affiliation:** Dongseo University, Engineering & Design Convergence Team  
📌 **Objective:** Develop an **intuitive educational device** that enables visually impaired individuals to learn **both Braille and Hangul simultaneously** through tactile feedback.  

---

## 🌟 Introduction  
Visually impaired individuals face challenges in accessing information and educational opportunities.  
In particular, **the low Braille literacy rate limits their communication and social participation**.  

📌 **Solution:**  
✅ Develop a **digital learning device** that facilitates **simultaneous learning of Braille and Hangul**  
✅ Utilize **solenoid-based tactile feedback technology** to provide **intuitive** learning  
✅ Establish a **web-integrated learning system** to enhance user convenience  

---

## 🔍 Background & Problem Statement  
📊 **Current Situation of the Visually Impaired**  
- Among **252,703 registered visually impaired individuals** in South Korea, only **9.6% can read Braille**  
- Less than **1 in 10** visually impaired individuals are proficient in Braille  
- Existing Braille learning devices are **expensive and difficult to use**, limiting accessibility  

📌 **Problems to Solve:**  
✔️ **Improve accessibility to Braille learning** → Develop an intuitive and affordable system  
✔️ **Establish a tactile-based learning system**  
✔️ **Develop a cost-effective and practical Braille learning device**  

---

## 💡 Key Idea: Intuitive Learning Device "Dodam"  
🔹 **Core Features**  
✅ **Simultaneous learning of Braille and Hangul**  
✅ **Solenoid-based tactile feedback technology** for intuitive learning  
✅ **Web-integrated interface** for enhanced user convenience  

📊 **Device Overview**  
| Feature | Description |  
|---------|------------|  
| **Braille Display** | Uses solenoids to generate Braille in a tactile format |  
| **Hangul Display** | Uses the same solenoid system to display Hangul characters |  
| **Repetition Function** | Users can repeat words for reinforcement |  
| **Web Integration** | Users can enter words via a web interface and receive real-time output on the device |  

📌 **Expected Benefits:**  
✅ **Convenient Learning** – Instantly outputs desired characters for immediate study  
✅ **Engaging Experience** – Motivates users by enabling simultaneous Braille and Hangul learning  
✅ **Sustainable Usage** – Continuous electrical supply allows dynamic character generation  

---

## 🔧 Device Design & Implementation  
### 🛠 Hardware Configuration  
| **Component** | **Quantity** | **Function** |  
|--------------|------------|-------------|  
| Braille Solenoids | 12 | Provides tactile Braille feedback |  
| Hangul Solenoids | 64 | Generates tactile Hangul characters |  
| Braille Module Boards | 13 | Handles Braille input system |  
| Power Supply (SMPS) | 1 | Supplies power to the entire system |  

### 🖥 Software Configuration  
- **Flask-based Web UI** → Enables users to input words, which are then processed and displayed on the device  
- **Arduino Control System** → Converts input data into solenoid-driven Braille & Hangul outputs  

📌 **Operational Workflow:**  
1️⃣ Users input words via a web interface  
2️⃣ **Arduino** processes the input and converts it into Braille & Hangul data  
3️⃣ Solenoids generate **tactile Braille & Hangul output**  
4️⃣ Users **read by touch** and learn simultaneously
